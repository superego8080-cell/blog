Sino ang Nakikinig? | Blog

A simple and responsive Filipino blog webpage about the importance of listening, understanding, and effective communication.

sino-ang-nakikinig/
│
├── index.html
├── style.css

📝 Description

Sino ang Nakikinig? is a blog-style website designed to discuss the importance of being a good listener.

The webpage includes:

A header with the blog title and introduction

A sticky navigation bar

A main blog article

A featured/hero image

Sections explaining the importance of listening

Examples of good listening

Tips for becoming a better listener

Questions for reflection

An inspirational quote

A "Tandaan" reminder section

A footer

Responsive styling for mobile devices

🛠️ Technologies Used

HTML5 — Used to structure the webpage

CSS3 — Used for styling, colors, layouts, gradients, shadows, and responsiveness

No external frameworks or libraries are required.

🚀 How to Run

Download or clone the project.

Make sure the following files are in the same folder:

index.html
style.css


If you are using an image, place it in the same folder as well.

Open index.html in any modern web browser.

You can also use a code editor such as Visual Studio Code and open the project folder there.

🖼️ Adding the Blog Image

The HTML contains an image similar to:

<img
    src="your-image.jpg"
    alt="Sino ang Nakikinig?"
    class="hero-image"
>


Replace your-image.jpg with the actual filename of your image.

For example:

<img
    src="listening.jpg"
    alt="Sino ang Nakikinig?"
    class="hero-image"
>


Then place listening.jpg inside the project folder.

🎨 Design

The website uses a warm and colorful design with:

Dark blue navigation and footer

Orange and yellow gradients

Soft purple backgrounds

Rounded content cards

Drop shadows

Responsive layouts

Hover effects for navigation links

📱 Responsive Design

The website includes a CSS media query for smaller screens.

On mobile devices:

Header text becomes smaller

Blog title scales down

Article padding is reduced

Navigation links adjust to fit smaller screens

Quote text becomes smaller

📌 Navigation

The navigation contains links to different sections of the webpage:

Link	Section
Home	Top of the webpage
Article	Main article
Tips	Listening tips
Questions	Reflection questions
✏️ Customization

You can customize the website by editing style.css.

For example, to change the main background:

body {
    background: #ffffff;
}


To change the header colors:

header {
    background: #172b46;
}


You can also change fonts, spacing, colors, borders, shadows, and other visual elements.
